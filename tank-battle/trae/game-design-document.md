# 3D坦克大战游戏设计文档

## 游戏概述

### 游戏名称
方块坦克竞技场 (Block Tank Arena)

### 核心玩法
- 3D物理坦克对战游戏
- 玩家可自定义坦克组件
- 基于物理碰撞的战斗系统
- 速度加成伤害机制
- 组件品质通过颜色区分

### 技术栈
- Three.js (3D渲染)
- Cannon.js (物理引擎)
- WebGL (浏览器原生支持)
- HTML5/CSS3 (界面)

## 游戏机制设计

### 1. 物理系统
- **重力**: 标准重力 9.8 m/s²
- **碰撞**: 真实物理碰撞检测
- **摩擦力**: 地面摩擦系数 0.8
- **弹性**: 碰撞弹性系数 0.3

### 2. 坦克组件系统

#### 组件类型
1. **引擎组件**
   - 决定坦克移动速度
   - 影响坦克总重量
   - 品质决定速度上限

2. **装甲组件**
   - 提供坦克血量
   - 增加坦克重量
   - 品质决定防御力

#### 组件品质 (颜色区分)
- **普通 (灰色)**: 基础属性
- **优秀 (绿色)**: 属性提升 20%
- **稀有 (蓝色)**: 属性提升 50%
- **史诗 (紫色)**: 属性提升 100%
- **传说 (橙色)**: 属性提升 200%

#### 组件重量公式
```
重量 = 基础重量 × (1 + 品质系数)
品质系数: 普通(0), 优秀(0.2), 稀有(0.5), 史诗(1.0), 传说(2.0)
```

### 3. 战斗系统

#### 伤害计算
```
碰撞伤害 = 基础伤害 × (相对速度/最大速度) × 重量比

其中:
- 基础伤害 = 50
- 相对速度 = 两坦克相对速度
- 重量比 = 攻击方重量 / 防御方重量
```

#### 血量系统
- 每个组件独立血量
- 组件损坏影响对应功能
- 引擎损坏降低移动速度
- 装甲损坏降低防御力

### 4. 移动系统

#### 控制方式
- WASD: 移动
- 鼠标: 视角控制
- 空格: 急停

#### 移动公式
```
最大速度 = 引擎功率 / 坦克总重量
加速度 = 引擎功率 × 0.1 / 坦克总重量
```

### 美术风格
- 极简方块风格
- 纯色材质
- 无纹理贴图
