# 方块坦克竞技场 (Block Tank Arena)

一个基于Three.js的3D坦克对战游戏，玩家可以自定义坦克组件，通过物理碰撞进行战斗。

## 游戏特色

- **3D物理引擎**: 使用Cannon.js实现真实的物理碰撞和运动
- **组件系统**: 可自定义的坦克引擎和装甲组件
- **物理战斗**: 基于速度和质量的碰撞伤害系统
- **多种游戏模式**: 训练模式、对战模式、生存模式
- **简洁美观**: 使用方块和球体构建的3D坦克
- **实时特效**: 粒子系统、爆炸效果、音效

## 快速开始

### 本地运行

1. 确保已安装Python 3.x 或 Node.js

2. 使用Python启动本地服务器：
   ```bash
   python -m http.server 8000
   ```

   或使用Node.js：
   ```bash
   npx http-server -p 8000
   ```

3. 在浏览器中访问：
   ```
   http://localhost:8000
   ```

### 游戏控制

- **移动**: W(前进) / S(后退) / A(左转) / D(右转)
- **刹车**: 空格键
- **相机**: 鼠标拖拽旋转视角，滚轮缩放
- **菜单**: ESC键暂停/继续

## 游戏模式

### 训练模式
- 无限血量，用于熟悉操作
- AI坦克会无限重生
- 无时间限制

### 对战模式
- 5分钟限时战斗
- 击败所有AI坦克获胜
- 时间结束则失败

### 生存模式
- 无限波次的敌人
- 每30秒生成一波更强的AI
- 生存时间越长分数越高

## 组件系统

### 引擎类型
- **基础引擎**: 绿色，中等速度，中等重量
- **高速引擎**: 蓝色，高速度，高重量
- **轻型引擎**: 黄色，低速度，低重量

### 装甲类型
- **基础装甲**: 绿色，中等血量，中等重量
- **重型装甲**: 蓝色，高血量，高重量
- **轻型装甲**: 黄色，低血量，低重量

## 物理系统

- **质量影响**: 组件重量影响坦克的移动和碰撞
- **速度加成**: 高速碰撞造成更多伤害
- **动能计算**: 基于质量和速度的物理伤害
- **真实碰撞**: 坦克之间的物理交互

## 技术栈

- **Three.js**: 3D图形渲染
- **Cannon.js**: 物理引擎
- **WebGL**: 硬件加速渲染
- **Web Audio API**: 音效系统
- **HTML5/CSS3**: 界面和样式

## 浏览器支持

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+

需要支持WebGL和Web Audio API的现代浏览器。

## 调试功能

- **F1**: 显示帮助信息
- **F2**: 切换物理调试模式
- **F3**: 重置相机位置
- **ESC**: 暂停/继续游戏

## 故障排除

### 游戏无法启动
1. 检查浏览器是否支持WebGL
2. 清除浏览器缓存
3. 尝试使用其他浏览器

### 性能问题
1. 降低浏览器窗口大小
2. 关闭其他标签页
3. 检查显卡驱动更新

### 物理异常
1. 按F2开启物理调试模式
2. 检查控制台错误信息
3. 尝试刷新页面
