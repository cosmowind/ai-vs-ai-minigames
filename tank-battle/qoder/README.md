# 🚗💥 3D坦克大战 - Tank Battle

一款基于Web技术的3D坦克大战游戏，具有完整的组件系统、物理引擎和真实碰撞伤害机制。

## 🎮 游戏特色

### 核心玩法
- **组件化坦克构建**：自由组装引擎、装甲等组件
- **物理驱动战斗**：基于Cannon.js的真实物理碰撞
- **速度加成伤害**：高速撞击造成更大伤害
- **重量平衡策略**：引擎性能与重量的权衡选择

### 技术特点
- **纯Web实现**：基于Three.js + Cannon.js，无需额外安装
- **组件系统**：模块化的坦克构建机制
- **品质系统**：通过颜色区分组件品质（白/绿/蓝/橙）
- **真实物理**：完整的质量、速度、碰撞计算
- **简约美学**：基础几何体构建的3D模型

## 🚀 快速开始

### 环境要求
- 现代浏览器（Chrome 80+, Firefox 75+, Safari 13+, Edge 80+）
- 支持WebGL
- 启用JavaScript

### 启动游戏

#### 方法1：本地服务器（推荐）
```bash
# 在项目目录下启动HTTP服务器
python -m http.server 8000
# 或者使用Node.js
npx serve .
```
然后访问：http://localhost:8000

#### 方法2：直接打开
双击 `index.html` 文件（某些功能可能受限）

## ⚔️ 战斗机制

### 伤害计算
- **基础伤害** = 碰撞动能 × 伤害系数
- **速度加成**：
  - 0-10 km/h：0.5倍伤害
  - 10-30 km/h：标准伤害
  - 30-50 km/h：1.5倍伤害
  - 50-70 km/h：2.0倍伤害
  - 70+ km/h：2.5倍伤害

### 物理特性
- **重量影响**：重型坦克撞击力更强，但机动性较差
- **装甲吸收**：装甲优先承受伤害，破坏后影响坦克本体
- **真实碰撞**：基于质量、速度的真实物理计算

## 🎯 游戏目标

1. **坦克配置**：在左侧面板选择组件构建坦克
2. **验证配置**：确保坦克满足最低要求（引擎+底盘）
3. **部署战斗**：点击"构建坦克"进入战场
4. **驾驶作战**：使用WASD控制坦克移动和战斗
5. **碰撞伤害**：通过高速撞击摧毁敌方坦克

- **渲染优化**：阴影和光照优化

## 🐛 故障排除

### 常见问题
1. **游戏无法启动**：检查浏览器兼容性和WebGL支持
2. **帧率过低**：降低画质设置或关闭其他程序
3. **坦克控制异常**：检查键盘焦点和按键绑定
4. **碰撞无效果**：确保物理系统正常初始化

### 技术支持
- 检查浏览器控制台错误信息
- 确保使用最新版本的现代浏览器
- 网络问题可能影响CDN资源加载
