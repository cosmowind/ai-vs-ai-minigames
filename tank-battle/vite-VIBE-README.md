# 3D坦克大战

一个基于Unity开发的物理驱动3D坦克战斗游戏，玩家可以通过自定义坦克组件，在完全遵循物理规律的环境中进行激烈碰撞战斗。

## 🎮 游戏特色

- **物理驱动战斗**: 完全真实的物理碰撞，速度影响伤害
- **组件化定制**: 自由装配引擎、车身、武器等组件
- **策略深度**: 不同组件组合产生不同战术玩法
- **简洁美术**: 纯几何体风格，方块+球体构成

## 📋 核心机制

### 坦克组件系统
- **引擎**: 提供速度，越快引擎重量越大
- **车身**: 提供血量，越坚固重量越大
- **武器**: 撞角、装甲板、尖刺等
- **辅助**: 平衡器、加速器、护盾等

### 物理伤害系统
- 碰撞伤害 = 动能 × 速度加成 × 组件加成
- 质量和速度共同决定伤害强度
- 角度影响伤害系数

## 🛠️ 技术栈

- **引擎**: Unity 2022.3 LTS
- **语言**: C#
- **物理引擎**: Unity PhysX
- **渲染**: Unity URP

## 🚀 开发计划

项目分为4个主要阶段，共8周开发时间：

### Phase 1: 核心框架 (第1-2周)
- 项目初始化
- 基础场景搭建
- 物理系统配置

### Phase 2: 组件系统 (第3-4周)
- 组件框架设计
- 引擎与普通组件实现
- 装配系统开发

### Phase 3: 战斗系统 (第5-6周)
- 伤害计算系统
- 特效与音效
- 平衡性调整

### Phase 4: 游戏流程 (第7-8周)
- 完整游戏流程
- UI系统完善
- 性能优化
